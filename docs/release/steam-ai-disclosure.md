# Steam AI-content disclosure (draft for the Content Survey, section 3)

Sources read 2026-10-21: partner.steamgames.com/doc/gettingstarted/contentsurvey and Valve's "AI Content on Steam"
announcement. Pre-generated AI content must be disclosed; Valve shows much of it on the store page and reviews the output
like any other content (no infringing content, must match the store page). Some answers can't be edited after release
without Steam Support, so update this draft before submitting.

Draft:
"Kaiju Incremental contains pre-generated AI content made during development: music made with Suno, sound effects made
with ElevenLabs, and 3D kaiju models first designed with Tripo and then rigged and edited by hand. All of it was generated
before release and ships fixed in the game. The game uses no AI while it runs. We hold commercial licences for the
generated assets."
